# Mladen Anđelković — veb sajt

Statična početna strana (HTML, bez build koraka).

## Objavljivanje na GitHub Pages
1. Otpremi sadržaj ovog foldera (index.html i folder images/) u koren repozitorijuma.
2. Settings → Pages → Source: "Deploy from a branch", grana `main`, folder `/ (root)`.

## Za dopunu
- Broj telefona (`[broj telefona]` i `href="tel:"`)
- Linkovi "Pošalji poruku" i "Saznaj više" (trenutno `#`)
- Utisci klijenata
